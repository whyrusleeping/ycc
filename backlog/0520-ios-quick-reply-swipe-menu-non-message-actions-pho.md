## Description
Idea from the owner while designing 0514: the swipe menu could also hold actions that aren't messages, e.g. attach a photo, start a new session, or voice input. The menu would mix them with quick replies, as in a reference app the owner shared. The owner wants to think on it after using the reply-only menu.

**Acceptance (if accepted):** chosen actions appear in the swipe menu, set visually apart from message replies, and trigger the same flows as their existing buttons.
